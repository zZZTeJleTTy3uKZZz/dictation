# Словарь терминов диктовки.
#
# Один файл на все четыре программы: служба берёт отсюда подсказку для
# распознавания и для причёсывания, плагин Harness — для своего причёсывания,
# значок показывает путь к нему. Живая копия лежит в
# %ProgramData%\Dictation\glossary.txt, и править надо её: этот файл — только
# начальный набор, который служба кладёт на место, если живого нет.
#
# Формат: одна строка — один термин. Пустые строки и строки с # пропускаются.
# Строки идут по важности: распознаванию отдаются первые из них (у подсказки
# Groq окно в 224 токена), причёсыванию — весь список.
#
# Добавить термин просто: `dictation.exe glossary add "Лидоруб"` или руками в
# файл. Слова, которые распознавание путает, видно по журналу правки.
#
# Откуда эти слова: из собственных диктовок человека (notes.jsonl обеих машин) —
# названия его программ, сущностей и отчётов. Ничего не выдумано.
#
