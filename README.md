# Диктовка

Диктовка — программа для Windows: нажимаете сочетание клавиш, говорите, и
распознанный текст появляется в том поле, где стоит курсор. История фраз,
повторная расшифровка и настройки — в отдельном окне. Звук никуда не
отправляется до вашего разрешения: распознавание идёт через облако, которое
вы выбираете сами.

Поддерживается Windows x64. По умолчанию установка для всех пользователей
компьютера: нужны права администратора, Windows покажет запрос UAC. Для установки
только для текущего пользователя прав не нужно, см. ниже.

## Установка и удаление

PowerShell:

```powershell
irm https://github.com/zZZTeJleTTy3uKZZz/dictation/releases/latest/download/install.ps1 | iex
```

cmd:

```cmd
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://github.com/zZZTeJleTTy3uKZZz/dictation/releases/latest/download/install.ps1 | iex"
```

Команда скачивает установщик `Dictation-Setup.exe` последнего выпуска, сверяет
его SHA-256 с манифестом и ставит тихо. Без прав администратора сценарий сам
перезапускается с запросом UAC; если запрос отклонить, установка не выполняется.
Поставится служба Windows, она поднимает программу для всех пользователей.

Установка только для себя (прав администратора не нужно, службы не будет,
автозапуск в сеансе):

PowerShell:

```powershell
& ([scriptblock]::Create((irm https://github.com/zZZTeJleTTy3uKZZz/dictation/releases/latest/download/install.ps1))) -CurrentUser
```

cmd:

```cmd
powershell -NoProfile -ExecutionPolicy Bypass -Command "& ([scriptblock]::Create((irm https://github.com/zZZTeJleTTy3uKZZz/dictation/releases/latest/download/install.ps1))) -CurrentUser"
```

Параметры работают только в этой форме: при `irm … | iex` параметров нет, и
установка идёт в режиме по умолчанию (для всех).

Удаление:

```
dictation uninstall
```

## Первая настройка

При первом запуске окно покажет две большие кнопки:

* **Groq** — самый простой путь. Нажмите «Создать ключ в Groq», чтобы открыть
  [личный кабинет](https://console.groq.com/keys), скопируйте ключ и вставьте
  его в поле. Ключ проверяется пробным запросом; после успеха Диктовка
  сохраняет его защищённым (DPAPI) и пишет «Готово — нажмите Ctrl+Space».
* **Свой провайдер** — вставьте ссылку подключения или укажите адрес, модель и
  ключ вручную. Подойдёт любой сервис, говорящий на языке OpenAI.

Ключ не попадает ни в историю, ни в журнал, ни в настройки открытым текстом.
Если облако недоступно, фраза не теряется: она остаётся в истории со статусом
«ждёт повтора», а кнопка «Расшифровать заново» позволяет повторить её в любой
момент.

Сочетание клавиш по умолчанию — **Ctrl+Space**. Его можно изменить в разделе
«Управление записью»: нажмите «Изменить» и нажмите новое сочетание. Если его
уже заняла другая программа, Диктовка скажет об этом первой строкой в меню и
в журнале.

## Обновление

Программа сама раз в шесть часов проверяет, вышла ли новая версия, и
показывает карточку в разделе «Настройки → О программе». Источник — публичный
[манифест выпуска](https://github.com/zZZTeJleTTy3uKZZz/dictation/releases/latest/download/update.json),
авторизация не нужна. Кнопка «Проверить обновления» запускает проверку сразу.

Если сервис обновлений недоступен, на экране появляется одна строка
«Не удалось проверить обновления — нет связи с GitHub» и кнопка «Повторить».
Технические детали уходят только в журнал, а не на экран.

Для разработки адрес манифеста можно переопределить переменной среды
`DICTATION_UPDATE_MANIFEST`; обычному пользователю это делать не нужно.

## Файлы настроек

Настройки и история лежат в `%ProgramData%\Dictation`, записи и временные
файлы — в `%LOCALAPPDATA%\Dictation`. Журнал работы — `dictation.log` рядом с
настройками. Если файл остался от прежней версии и его нельзя открыть,
программа пишет события в запасной файл и сообщает причину в stderr.

## Сборка из исходников

Сборка из исходников не требует доступа к приватным модулям: нужные части kits лежат в third_party; готовые бинарники —
в [Releases](https://github.com/zZZTeJleTTy3uKZZz/dictation/releases). Окно
собирается из каталога `flutter`. Состав публичного дерева описан в
`release/public-tree.txt` и проверяется сценарием `scripts/public-check`.
